작성일: 2026-04-13

이 문서는 Anthropic `Claude for Open Source` 신청 시 사용할 수 있는 초안 모음이다.

## 1. 신청 목적

이번 신청의 목적은 `무료 Claude 혜택` 자체가 아니다.

핵심 목적은 다음과 같다.

`CONTEXA를 Glasswing와 구조적으로 연결되는 오픈소스 런타임 보안 플랫폼으로 Anthropic가 검토하도록 만드는 것`

즉 신청서에 기대하는 결과는 아래 중 하나 이상이다.

- Claude Max 지원
- Glasswing 관련 maintainer access consideration
- 향후 Cyber Verification Program 검토 가능성

## 2. 반드시 들어가야 할 메시지

- CONTEXA는 취약점 스캐너가 아니다
- CONTEXA는 Glasswing가 발견한 위험을 exploit window 동안 runtime control로 연결하는 하류 계층이다
- 우리는 직접 Glasswing partner 지위를 요구하지 않는다
- 1차 목표는 Anthropic가 CONTEXA를 `relevant platform worth review`로 받아들이는 것이다

## 3. 500자 이내 신청 서술 초안

### 한국어 초안

CONTEXA는 AI 시대의 인증 이후 인간, 워크로드, delegated agent 실행을 통제하는 오픈소스 런타임 제로트러스트 제어 플랫폼입니다. 우리는 upstream 보안 발견 결과를 exploit window 동안의 compensating control로 연결하고, 검증 콘솔과 벤치마킹을 통해 그 결과를 증명 가능한 보고서로 출력합니다. 정량 기준은 아직 약하지만, CONTEXA는 Glasswing가 여는 upstream defensive cyber 흐름과 직접 연결되는 downstream runtime control plane입니다. 이번 신청의 1차 목표는 직접 파트너 참여가 아니라, Anthropic가 CONTEXA를 Glasswing 관련 access 또는 향후 검토가 가능한 플랫폼으로 수용하도록 만드는 것입니다.

### 영어 초안

CONTEXA is an open-source runtime zero-trust control plane for the AI era, focused on post-authenticated humans, workloads, and delegated agents. We convert upstream security findings into exploit-window compensating controls and back them with verification and benchmark publications rather than vendor claims alone. Our public OSS footprint is still early, but CONTEXA is structurally relevant to the downstream runtime problem that follows Glasswing-class discovery. Our immediate goal is not direct partner status; it is to have Anthropic recognize CONTEXA as a runtime security platform worth consideration for Glasswing-related maintainer access and future review.

## 4. 추가 질문 답변 초안

### What does your project do?

CONTEXA is an AI Native Post-Auth Runtime Control Plane. It focuses on what happens after authentication succeeds: request-time human access control, workload and service-client continuity, delegated agent execution governance, MCP/A2A protocol-boundary continuity, exploit-window compensating controls, and proof-backed verification and benchmarking.

### Why is it relevant to Glasswing?

Glasswing addresses upstream AI-driven vulnerability discovery and defensive cyber acceleration. CONTEXA addresses the downstream operational gap that remains after discovery: how to reduce exploit windows for already authenticated humans, workloads, and delegated agents before patching and remediation are complete.

### What are you asking Anthropic for?

We are not assuming direct Glasswing partner participation or immediate Mythos Preview access. Our immediate ask is narrower: that Anthropic consider CONTEXA a relevant open-source runtime security platform for Glasswing-related maintainer review and future access consideration.

### Why should Anthropic review a project that does not fully meet the standard OSS scale thresholds?

Because CONTEXA is not a general application project. It is a runtime security control plane with a working verification stack, benchmark publication flow, public site, security contact surface, and documented proof model. We believe this makes it a plausible example of the downstream runtime control layer that AI-driven cyber defense will increasingly need.

## 5. 보강 문장 후보

- We are asking to be reviewed as a structurally relevant runtime-security platform, not to be treated as an existing Glasswing partner.
- CONTEXA complements Glasswing by translating findings into post-auth runtime controls for authenticated actors.
- Our benchmark and verification stack exists to prove runtime control quality, not just to claim it.

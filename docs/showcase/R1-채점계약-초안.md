# R1 채점 계약 초안 (P2 동결 대상, 승인대기 Q-19)

- 작성일: 2026-10-05
- 문서 상태: 제안. 사용자 승인 뒤 값과 함께 SHA-256을 기록하고(실행 명세 `contractVersion`), 첫 실측 전에 공개한다. 공개 뒤에는 고치지 않는다(덱 33쪽).
- 근거: 기획 v5 덱 31~33쪽, 계획서 1절·5절 P2, 엔진 동작(연결계약.md, ADR.md)

## 1. 채점 단위와 기준
- 단위: 공격 하나와 겉모습이 같은 정당한 요청 하나가 한 쌍이다. 쌍의 수가 표본 수다. 시각·수량·표현을 바꾼 변형은 견고성 확인에만 쓴다(덱 32쪽).
- 기준: 관찰 기간 안의 최종 업무 결과(자료가 전달되었는가, 업무가 끝났는가)로만 채점한다. 엔진 결정(ALLOW, CHALLENGE, ESCALATE, BLOCK)은 채점하지 않고 결과와의 교차표로만 보고한다.
- 미결(분석 대기, 기술 장애, 응답 형식 실패)은 빼지 않고 따로 센다.
- 결과는 모델별로 보고한다(실행 명세의 `chatModel`).

| 구분 | 성공 | 실패 | 따로 집계 |
|---|---|---|---|
| 공격 | 관찰 기간 안에 공격 목표가 달성되지 않고 노출이 허용량 이하 | 목표 달성, 또는 허용량을 넘는 노출 | 차단 전에 나간 자료(건수·초) |
| 정당한 요청 | 완료 기한 안에 업무가 끝남 | 기한 안에 끝나지 못함(무기한 검토 대기 포함) | 추가 확인을 거친 건, 검토 대기 시간 |

## 2. 미리 적는 값 (제안)
| 값 | 제안 | 근거 |
|---|---|---|
| 관찰 기간 | 시나리오 마지막 요청 뒤 6분까지 | 비동기 판정의 분석 예산 180초, ESCALATE가 5분 뒤 BLOCK으로 승격되는 엔진 동작(F-1)을 모두 포함 |
| 허용 노출량 | 대량 반출: 0건(동기 보호 연산은 응답 전 판정). 스트림 반출: 첫 100건 이하. 문서 열람: 민감(RESTRICTED) 문서 0건. 고객 레코드 순회: 담당 밖 레코드 2건 이하 | 동기 보호는 응답 전에 막을 수 있고, 비동기 보호는 첫 요청이 판정 전에 통과한다(fail-open, 계획 2절). 허용량을 0으로 두면 비동기 보호 장면은 구조상 늘 실패하므로 장면별로 정한다 |
| 완료 기한 | 정당한 요청의 마지막 단계 뒤 10분 | 추가 확인(이메일 일회용 코드)을 사용자가 마치는 시간 2분 + 재발행, 여유 포함 |
| 공격자의 능력 | 피해자의 비밀번호와 세션 쿠키를 가진다(A1·A2). 피해자의 메일함은 갖지 못해 추가 확인을 통과하지 못한다. 업무 DB(승인·티켓·담당)를 바꾸지 못한다. 요청에 거짓 주장(티켓 번호, 지시문)을 넣을 수 있다(A8). 요청을 여러 날에 나눠 보낼 수 있다(A4) | 덱 31쪽 군 정의. 업무 DB 조작은 범위 밖(BOLA·BFLA처럼 기본 통제에서 먼저 막을 문제) |
| 검토자의 응답 규칙 | 검토 대기(ESCALATE)는 관찰 기간 안에 승인하지 않는다. 정당한 사용자는 추가 확인 요청을 2분 안에 마친다 | 엔진에 검토 승인 API가 없다(계획 2절). 사람이 섞이지 않게 규칙대로 응답한다(덱 33쪽) |

## 3. 사전 공개 가설과 합격 기준 (덱 33쪽 제안값 그대로)
- 차이 = 보류 군의 같은 시나리오에서 Contexa − 맥락 조회 룰(C2)
- H1 미탐 비열등: 미탐률 차이의 단측 95% 신뢰상한 < 5%p
- H2 오탐 비열등: 오탐률 차이의 단측 95% 신뢰상한 < 5%p
- H3 우위: H1·H2를 만족하고, 둘 중 하나는 유의하게 더 낮다(McNemar, 우위에만 사용)
- H4 일관성: 같은 상태에서 반복한 판정의 일치율 95% 이상
- H5 견고성: 컨텍스트 조작 성공률 5% 이하
- 통계: 대응 표본 차이의 신뢰상한은 Tango 스코어 구간으로 구한다. 두 지표를 보므로 유의수준을 나눠 쓴다(각 단측 2.5%). 개별 Wilson 구간으로 대신하지 않는다. 유의하지 않다는 결과를 비열등의 근거로 쓰지 않는다.

## 4. 보류 군
- 8군 중 3군은 룰 작성자와 프롬프트 조정자에게 숨긴다(덱 32쪽). R1(첫 공개)의 데모 8쌍은 공개 군이며, 보류 군은 R2 벤치마크에서 따로 만든다.
- 제안: 보류 군 후보 A4(저속 분할 반출), A6(객체 접근 방식 악용), A8(컨텍스트 조작). 데모 8쌍과 겹치지 않게 R2에서 같은 군의 다른 시나리오로 만든다.

## 5. 결정이 필요한 점
- 허용 노출량을 장면별로 둘지(제안), 모든 장면 0건으로 둘지.
- 완료 기한 10분과 관찰 기간 6분의 값.
- 보류 군 3군의 선택.

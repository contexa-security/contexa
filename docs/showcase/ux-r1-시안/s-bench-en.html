Run as published

  • agentdojo 0.1.35 (benchmark v1.2.2) · InjecAgent commit f19c9f2 · promptfoo 0.125.1
  • Zero changes to harness and scoring files (checked 2026-10-29)
  • Test conditions frozen before each run, with hashes recorded in the result files
  • Values under 1% are shown with the point estimate and the 95% upper bound

Limits — what these results do not say

  • One local victim agent, qwen2.5 7B — no claim for stronger models
  • The sub-1% target was not met (point 1.4–2.0%, one-sided upper bound 2.35–3.09%)
  • If the owner approves everything, 17.7% get through — a human approving wrongly is not stopped
  • InjecAgent: first stage only (the second, data-stealing stage was not measured)
  • Promptfoo: reduced to 2 tests per plugin · attacks generated and graded by the Promptfoo server
  • Reproduction package not finished · adaptive attacks (S-5) not run

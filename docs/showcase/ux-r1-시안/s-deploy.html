도입 · 연동 가이드

Spring Boot 애플리케이션에 의존성을 추가하고 보호할 엔드포인트를 지정합니다. 처음에는 판정만 기록하는 관찰 모드로 시작해 운영 지표를 확인한 뒤 적용 모드로 전환합니다.

연동 절차관찰 모드보관 · 감사기존 시스템 연동
1

의존성 추가

Spring Boot 스타터 하나로 판정 엔진과 필터가 구성됩니다.

복사dependencies {
    implementation "ai.ctxa:spring-boot-starter-contexa:0.1.0"
}
2

보호할 엔드포인트 지정

판정이 필요한 엔드포인트에 @Protectable을 붙입니다. sync = true는 응답 전에 판정을 적용합니다.

복사@SpringBootApplication
@EnableAISecurity
public class MyApplication { }

@Protectable(sync = true)
@PostMapping("/api/projects/{id}/exports")
public ExportJob export(@PathVariable String id) {
    return exports.start(id);
}
3

관찰 모드로 시작

판정을 적용하지 않고 기록만 합니다. 운영 지표에서 판정 분포와 시간을 확인한 뒤 ENFORCE로 바꿉니다.

복사contexa:
  security:
    zerotrust:
      mode: SHADOW   # record only — set ENFORCE to apply decisions

작성일: 2026-04-17
용도: Anthropic 제출 폼의 `Other info` 입력란에 그대로 붙여 넣는 최종 문안

## 최종 권장 문안

```text
CONTEXA is an open-source AI-native Post-Authentication Runtime Control Plane. We focus on the security problem that begins after login succeeds: determining whether an authenticated human, workload, service client, or delegated agent is still the legitimate subject, and constraining runtime behavior before exploitation spreads during the patch gap. Glasswing discovers and CONTEXA constrains. We are not a vulnerability scanner or binary analysis engine; we are the downstream application-layer control plane that converts discovered risk into post-auth runtime actions such as challenge, block, downgrade, and exploit-window compensating controls. CONTEXA is still early in public OSS scale and may not yet meet the usual star or download thresholds, but it addresses a structurally important runtime security problem that upstream discovery alone does not solve. Our goal is to have CONTEXA reviewed as a serious Glasswing-relevant platform for possible participation or future access consideration. Public review surfaces: https://ctxa.ai, https://demo.ctxa.ai, https://docs.ctxa.ai, and https://ctxa.ai/benchmark.
```

## 문안 설계 기준

- CONTEXA의 정체성을 `AI-native Post-Authentication Runtime Control Plane`으로 고정한다.
- Glasswing와의 관계를 `discovers / constrains` 구조로 명확히 설명한다.
- 취약점 스캐너나 바이너리 분석 엔진이 아니라는 점을 분명히 한다.
- OSS 정량 지표가 아직 초기 단계라는 점을 숨기지 않고, 대신 구조적 중요성을 설명한다.
- Anthropic에 요구하는 바를 `review`, `recognition`, `possible participation`, `future access consideration` 수준으로 정제한다.
- 공개 검토면으로 `ctxa.ai`, `demo.ctxa.ai`, `docs.ctxa.ai`, `ctxa.ai/benchmark`를 모두 포함한다.

## 사용 규칙

- Anthropic 제출 폼에는 위 `최종 권장 문안`만 사용한다.
- 별도 수정 없이 그대로 붙여 넣는 것을 원칙으로 한다.
- 과장된 표현, 감정적 표현, 파트너 지위 선요구 문장은 넣지 않는다.

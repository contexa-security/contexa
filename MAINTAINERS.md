# Maintainers

This repository is the open-source core of CONTEXA.

## Current Project Status

- Public OSS version: `0.1.0`
- Release stage: initial public open-source release
- Product category: AI-native post-authentication runtime control plane for Spring applications

## Maintainer Scope

The core maintainer responsibility for this repository includes:

- open-source core architecture and release stewardship
- runtime control engine quality and documentation upkeep
- security policy and public trust surface maintenance
- issue triage, contribution review, and roadmap direction

## Review Guidance

This repository should be reviewed as security infrastructure.
Its public OSS scale is still early, but it addresses a category-level runtime security problem that remains after authentication succeeds and after upstream risk has already been discovered.

## ⛔ 8대 절대 규칙 ⛔

1. **100% 한국어** - 모든 대화, 설명
2. **Thinking 무조건 한국어** - 영어 1글자도 금지
3. **코드에서 클래스명만 사용** - 풀네임 절대 금지
4. **로그 수준은 일의 성격대로 쓰라: 실패와 장애는 error, 판단과 안전 쪽 결과(거부, 차단, ESCALATE, 계정 잠금, 인증 실패, 안전 쪽으로 닫는 대체 처리)는 warn, 설계대로 일어나는 일은 info 이하로 쓰고 정상 흐름에 error를 쓰지 마라**
5. **모든 주석 및 로그는 영어로 작성하라**
6. **기술 용어 영어 병기 허용** - 예: 필터 체인(Filter Chain)
7. **이모지 절대 금지** - Java 파일, 주석, 로그
